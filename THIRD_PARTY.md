# Third-party components

The application composes existing deterministic converters rather than implementing an AsciiDoc grammar.

| Component | Version | Source | License |
| --- | --- | --- | --- |
| Asciidoctor | 2.0.26 | https://github.com/asciidoctor/asciidoctor | MIT |
| asciidoctor-dita-topic | 1.5.3 | https://github.com/jhradilek/asciidoctor-dita-topic | MIT |
| dita-convert | 1.4.9 | https://github.com/jhradilek/dita-custom-xslt | MIT |
| lxml | 6.1.1 | https://lxml.de/ | BSD; see package notices for bundled libraries |

`schemas/dita-1.3/` is the unmodified `schema-url/` directory from DITA-OT 4.3.5, commit `1138a4018426f5fe26c257fcc0c3aa636dafe45d`, at `src/main/plugins/org.oasis-open.dita.v1_3/schema-url`. These are OASIS DITA 1.3 plus Errata 02 schemas. Copyright and licensing notices are retained in the files. The DITA-OT license is included at `schemas/DITA-OT-LICENSE`.

Source: https://github.com/dita-ot/dita-ot/tree/1138a4018426f5fe26c257fcc0c3aa636dafe45d/src/main/plugins/org.oasis-open.dita.v1_3/schema-url

`examples/con-role-based-access-control-in-rhdh.adoc` and `examples/proc-share-a-secret-with-ldap.adoc` come from `modules/shared/` in the Red Hat Developer Hub documentation repository at commit `3e977bb095f8ebfbe2d2695f8108e84e9002211e`. Its Apache 2.0 license is retained in `examples/UPSTREAM_LICENSE`. `examples/attributes.adoc` supplies a minimal explicit build context for those examples.

Source: https://github.com/redhat-developer/red-hat-developers-documentation-rhdh/tree/3e977bb095f8ebfbe2d2695f8108e84e9002211e/modules/shared

`examples/provided-reference.xml` is the compatibility example supplied by the project requester. It is intentionally preserved, including literal `+` paragraphs, and is not claimed to be generated by this application. `examples/reference.adoc` is a shorter representative example used to test the same DITA structures.
